# Layout catalogue

## 01_executive_summary

| id | zones | takeaway | use when |
|---|---|---|---|
| `exec_summary_kpi` | kpis[1-12], statements[1-12] | none | Business reviews / updates where 3-4 numbers frame the story. |
| `exec_summary_scr` | statements[1-12] | none | When the audience needs the problem framed before the answer (board, steering). |
| `exec_summary_statements` | statements[1-12] | none | Default executive summary: 3-5 key-line messages, each with 1-2 lines of proof. |

## 02_kpi

| id | zones | takeaway | use when |
|---|---|---|---|
| `kpi_grid` | kpis[1-12] | optional | When 4-6 metrics are the message and no single chart dominates. |
| `kpi_strip_exhibit` | kpis[1-12], exhibit[1-12] | optional | A few numbers set context and one chart carries the proof. |
| `kpi_strip_exhibit_commentary` | kpis[1-12], exhibit[1-8], commentary[9-12] | none | Performance slides: numbers, trend, and why. |

## 03_chart

| id | zones | takeaway | use when |
|---|---|---|---|
| `exhibit_full` | exhibit[1-12] | optional | The chart is self-explanatory; annotations carry the so-what. |
| `exhibit_pair` | exhibit[1-6], exhibit_2[7-12] | optional | Two views that together prove one point (e.g. size and growth). |
| `exhibit_trio` | exhibit[1-4], exhibit_2[5-8], exhibit_3[9-12] | optional | Same metric across three entities/segments (small multiples). |
| `exhibit_wide_narrow` | exhibit[1-8], exhibit_2[9-12] | optional | A main chart plus a zoom/decomposition of one element. |
